# AI-First SDE-II Engineering Portfolio

A portfolio of production-oriented software engineering projects
built while developing expertise in Java, Spring Boot, React,
PostgreSQL, software architecture, and AI engineering.

## Objectives

- Rebuild and deepen Java expertise.
- Develop industry-standard Spring Boot applications.
- Learn React and TypeScript from the fundamentals.
- Design relational data models using PostgreSQL.
- Apply maintainable architecture and SOLID principles.
- Practice data structures and algorithms.
- Develop low-level and high-level design skills.
- Implement AI capabilities, including LLM integration and RAG.
- Establish automated testing, CI/CD, security, and deployment.
- Document engineering decisions and trade-offs.

## Learning Approach

Projects will progress from intermediate to advanced and expert
levels. Each project will introduce new concepts while reusing
and strengthening previously acquired skills.

Each project should include, where applicable:

- Clear problem statement and requirements
- Architecture and design documentation
- Backend and frontend implementation
- Database schema and migrations
- Unit and integration tests
- Security considerations
- API documentation
- Local setup instructions
- Automated quality checks
- Deployment instructions
- Known limitations and future improvements

## Project Roadmap

The detailed roadmap will be maintained in `ROADMAP.md`.

Projects will be developed incrementally. A project is not
considered complete merely because its code compiles: testing,
documentation, security review, and reproducible setup are
required before release.

## Development Principles

- Prefer readable, maintainable code over unnecessary complexity.
- Use Maven for Java builds.
- Keep secrets and credentials out of source control.
- Test changes before committing them.
- Document important architecture decisions.
- Use AI tools as engineering assistants, with human review.
- Keep the default branch stable.
- Tag meaningful releases.
